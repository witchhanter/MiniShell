# MiniShell

**MiniShell** — это эмулятор командной строки (терминала), написанный на языке **1С:Элемент**. Проект реализует базовый набор команд для работы с файловой системой, выполнения HTTP-запросов, генерации QR-кодов и управления терминалом.

## Возможности

- Навигация по файловой системе (`cd`)
- Просмотр содержимого папок (`ls` с фильтрами и рекурсией)
- Работа с файлами (`touch`, `cat`, `rm`, `cp`, `mv`)
- Работа с папками (`mkdir`, `rmdir`)
- HTTP-запросы (`curl`)
- Генерация QR-кодов (`qr`)
- История команд (`history`, `!!`)
- Очистка экрана (`clear`)
- Выход из терминала (`poweroff`, `exit`)
- Справка по командам (`--help`, `help`)
- Получение информации о системе и пользователе (`arch`, `uname`, ..)
- Кроссплатформенность (Windows / Linux)
- Поддержка алиасов (`alias`)
- перенаправление вывода и перенаправление вывода с дозаписью для `ls` и `echo` в файл.txt

## Установка и запуск

1. Установите среду разработки **1С:Предприятие.Элемент**
2. Скачайте файл `MiniShell.sbsl`
3. Откройте файл в среде разработки
4. Нажмите **Выполнить** (CTRL + F5)

## Доступные команды

- `mkdir "<путь>" "<имя папки>"` — создаёт папку
- `clear` — очищает терминал
- `ls` — выводит список всех объектов в текущей папке
  - `ls dir` — выводит все директории в текущей папке
  - `ls .txt` — выводит все файлы `.txt` в текущей папке
  - `ls files` — выводит все файлы в текущей директории
  - `ls -r` — выводит объекты рекурсивно
  - `ls > "<файл.txt>"` - запись в пустой файл
  - `ls >> "<файл.txt>"` - запись в конец файла
- `cat "<файл>"` — показать содержимое файла
- `history` — показать историю введённых команд
- `cd "<путь>"` — изменить текущий рабочий каталог
- `!!` — повторить последнюю команду
- `poweroff` / `exit` — выйти из терминала
- `rm "<файл>"` — удалить файл
- `rmdir "<каталог>"` — удалить каталог со всем содержимым
- `touch "<файл>"` — создать пустой файл
- `cp "<источник>" "<назначение>"` — копировать объект
- `mv "<источник>" "<назначение>"` — переместить объект
- `curl "<url>"` — выполнить HTTP GET-запрос
- `qr "<текст>"` — сгенерировать QR-код
- `alias add "<алиас>" "<команда>"` — добавить алиас
- `alias remove "<алиас>"` — удалить алиас
- `date` - получить текущую дата
- `time` - получить текущее время
- `arch` - получить архитектуру процессора (аппаратную)
- `uname` - получить версию ядра
- `whoami` - получить имя авторизованного пользователя
- `echo "<текст>"` - вывести в консоль текст
  - `echo > "<файл.txt>"` - запись в пустой файл
  - `echo >> "<файл.txt>"` - запись в конец файла
- `help` — показать список всех команд
- `<команда> --help` — показать справку по команде

## Особенности

- **Кавычки обязательны** для путей, содержащих пробелы
- Для путей можно использовать как `\`, так и `/`
- История команд сохраняется в файл `commands.txt` в рабочей папке
- Команда `!!` не сработает, если предыдущей командой была `!!` (защита от бесконечного цикла)
- QR-коды сохраняются в рабочую папку с автоматической нумерацией (`QR_1.png`, `QR_2.png`...)

## При запуске отображается

- ASCII-арт логотипа
- Информация о системе:
  - Имя пользователя
  - Операционная система и версия
  - Архитектура
  - Текущая дата и время
  - Домашняя папка

## Системные требования

- **1С:Предприятие.Элемент Скрипт** (любая версия)
- Операционная система: Windows / Linux
